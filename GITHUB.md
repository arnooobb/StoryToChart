# Working versions

Repository: https://github.com/arnooobb/StoryToChart (private).

The original version lives in the repository root. The latest GPT-6 comparison version lives in `versions/2026-09-05-gpt6/`; read its `README.md` and `MEMORY.md` before continuing development there. Both versions include a standalone `index.html`.

Edit the chosen version's `src/` files, then run `node build.mjs` from that version's directory. Keep the generated HTML and source together in commits. The bundled Kite Tech example is fictional and Arnold approved its inclusion in this repository.

GitHub stores the application and its development history. Reports pasted into the running app stay in the browser; the application has no automatic upload. Do not add real case reports, saved case charts or credentials to the repository.

Arnold's requested comparison with Association Chart Builder v8 remains pending. Study its extraction logic and useful features, retain the preferred Story to Chart layout, and obtain approval for the plan before building an updated version.
